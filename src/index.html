Annuler les changements

      
Pendant l'installation, le script garde une copie de lui-même et un manifeste qui liste exactement ce qu'il a modifié. L'annulation lit ce manifeste : elle ne devine rien et ne touche à rien d'autre.

      
# 1. Voir ce qui sera annulé, sans rien changer
~/.local/share/mysh/mysh.sh --uninstall --dry-run

# 2. Annuler
~/.local/share/mysh/mysh.sh --uninstall

# 3. Annuler et supprimer aussi les paquets installés par Mysh
~/.local/share/mysh/mysh.sh --uninstall --remove-packages

      

        

          
ÉlémentCe que fait l'annulation

          
            
~/.zshrc, ~/.bashrcRetire le bloc entre # >>> mysh >>> et # <<< mysh <<<. Le reste du fichier n'est pas touché, y compris ce que tu as modifié après l'installation.

            
~/.config/mysh/Supprimé. Pour Fish : conf.d/mysh.fish supprimé.

            
starship.tomlTon ancien fichier est restauré. S'il n'existait pas, celui de Mysh est supprimé.

            
Logo~/.config/mysh/logo.txt supprimé. Ton ancienne configuration fastfetch est restaurée ; s'il n'y en avait pas, celle de Mysh est supprimée.

            
Starship, fastfetch, policeSupprimés s'ils ont été téléchargés par Mysh (dans ~/.local).

            
Shell par défautRemis à ton ancien shell (chsh demande ton mot de passe).

            
PaquetsConservés par défaut, car d'autres programmes peuvent en avoir besoin. Avec --remove-packages, seuls ceux que Mysh a installés sont supprimés.

          
        

      

      

        Annuler à la main, sans le script
        
    
          
  1. Ouvre ~/.zshrc (ou ~/.bashrc) et supprime les lignes entre les deux marqueurs mysh.
    2. 
          
  2. Supprime la configuration : rm -rf ~/.config/mysh
    3. 
          
  3. Retrouve tes fichiers d'origine : ls ~/.local/share/mysh/backups/, puis par exemple cp ~/.local/share/mysh/backups/<date>/starship.toml ~/.config/
    4. 
          
  4. Reviens à ton ancien shell : chsh -s /bin/bash
    5. 
        

      

      
Après l'annulation, le dossier est renommé en mysh.annule-<date> : tes sauvegardes y restent jusqu'à ce que tu le supprimes.

    


    

      
Pourquoi tu peux le lancer

      
    
        
  • Rien ne quitte ton navigateurLe script est assemblé ici, sans serveur, sans compte, sans statistiques.
    • 
        
  • Un script lisible, pas un binaireTu lis tout avant de lancer. sha256sum confirme que c'est bien ce fichier-là.
    • 
        
  • Dépôts officiels d'abordLes paquets viennent du gestionnaire de ta distribution, avec ses signatures.
    • 
        
  • Téléchargements épinglésStarship, fastfetch et la police ont leur empreinte SHA-256 écrite dans le script. Si elle ne correspond pas, le script s'arrête.
    • 
        
  • Jamais en rootLe script refuse de tourner en root et n'utilise sudo que pour installer les paquets.
    • 
        
  • Simulation et confirmation--dry-run montre chaque commande sans l'exécuter. Sinon, un résumé s'affiche et attend ton accord.
    • 
        
  • Tes fichiers sont sauvegardésCopie avant toute modification. Les fichiers système de /etc ne sont jamais remplacés.
    • 
        
  • Relançable sans risqueRelancer le script remplace le bloc au lieu de l'ajouter une deuxième fois.
    •
